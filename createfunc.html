Create Function

You can create a new function with the CREATE FUNCTION statement, which may clare a list of parameters, must return one value, and must define the actions to be erformed by the standard PL/SQL block.

Syntax of CREATE FUNCTION 

            CREATE [OR REPLACE] FUNCTION function_ name
             [(parameter1[mode1] datatype1,
              parameter2 [mode2] datatype2,
              ......)]

            RETURN datatype
            IS/AS

            [Local declaration]
            BEGIN
                  PL/SQL executable statements
            [EXCEPTION
                      Exception handlers]
            END [FUNCTION_NAME]

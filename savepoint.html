SAVEPOINTS



SAVEPOINTS identifies a point in a transaction to which user can later rollback with the ROLLBACAK statement.It is helpful when a transaction contains a large number of SQL statements and the user wants to commit only once when all are done.If requied, user can rolback to a particuler transaction.It works in a LAST IN FIRST OUT (LIFO) MANNER.

Syntax

 SAVEPOINTS S1;

Step1. SELECT * FROM STUDENT;


ROLL_NO Name Age City
1 PARAM 22 ALLAHABAD
2 ALKA 20 GHAZIABAD
3 DISHA 21 VARANASI
4 ESHA 21 DELHI


Step2. INSERT INTO STUDENT VALUES (5,"SHAM",32,"NEW DELHI");
1 row created.

Step3. SAVEPOINT S1;
Savepoint created.

Step4. UPDATE STUDENT
SET NAME='RAM'
WHERE ROLL_NO=1;
1 row updated.

Step5. ROLLBACK TO SAVEPOINT S1;
rollback complete.
(The ROLLBACK staement will undo the updation only.All transaction before the Savepoint 's1' will remain unchanged,but not yet commited.)

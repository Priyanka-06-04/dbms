Aggregate Functions

Group functions operate on multiple rows or groups of rows and return one value for the entire group or table. Group functions are also called Aggregate functions, used to produce the summarized results. They operate on sets of rows and return results based on groups of rows. By default all rows in a table are treated as one group.

In SQL, Group functions can be categorized as:
* COUNT()
* SUM()
* MAX()
* MIN()
* AVG()

COUNT()

This function returns the number of rows in the table that satisfies the condition specified in the WHERE clause. If the WHERE clause is not specified, then the query returns the total number of rows in the table.

Example: If you want to count the total number of STUDENTS working in a particular department, the query would be like:

SELECT COUNT (*) AS TOTAL_STUDENT FROM STUDENT
    
 WHERE DEPTNO=10;
OUTPUT:
TOTAL_STUDENT
5

SUM()

This function is used to get the sum of a numeric column.

Example: To get the total marks given out to the students, the query would be like: 
        SELECT SUM(marks) AS TOTAL_MARKS FROM STUDENT;
OUTPUT:
TOTAL_MARKS
209

MAX()

This function is used to get the maximum value from a column.

Example: To get the maximum marks obtained by an student, the query would be like: 
            SELECT MAX (marks) AS MAXIMUM_MARKS FROM STUDENT;
OUTPUT:
MAXIMUM_MARKS
45

MIN()

This function is used to get the minimum value from a column.

Example: To get the minimum marks obtained by an student, the query would be like: 
            SELECT MIN(marks) AS MINIMUM_MARKS FROM STUDENT;
OUTPUT:
MINIMUM_MARKS
34

AVG()

This function is used to get the average value from a column.

Example: To get the average marks obtained by an student, the query would be like: 
            SELECT AVG(marks) AS AVERAGE_MARKS FROM STUDENT;
OUTPUT:
AVERAGE_MARKS
41.8

%TYPE

To avoid and size conflict between a variable and the column of a table, the attribute %TYPE is used. Advantages of this method of defining a variable is that,whenever the type and/or size of a column in the table are changed, it is automatically reflected in the variable declaration.

Example:

Temp_name Emp_ename %type;
Here, the variable Temp_name will be of the same size and type as that of the Emp_ename column of EMP table.

%ROWTYPE

The %ROWTYPE attribute provides a record type that represents a row in a database table. The record can store ann entire row of data selected from table or fetched from a cursur or cursur variable.In case, variable for the entire row of a table need to be declared, then instead of declaring them individually, the attribute %ROWTYPE is used

Example:

Emp_row Emp%rowtype;
Here, the variable Emp_row will be of Composite variable, consisting of the column names of the table as its members.To refer to a specific variable,the following syntax will be used:

Emp_row.Sal:=5000;

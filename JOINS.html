Introduction

SOL Joins are used to relate information in different tables. Joins are used to combine columns from different tables. The connection between tables is established through the WHERE clause, called SQL Join condition. With Joins, the information from any number of tables can be accessed.

Syntax for joining tables:

        SELECT tablel.column, table2.column, ..., tableN. column

        FROM tablel, table2 ... tableN

        WHERE tablel.columnl = table2. column2;
TYPES OF JOINS
(i)EQUI join
(ii)Cartesian join
(iii)Outer join
(iv)Self join

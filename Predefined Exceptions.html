TYPES OF EXCEPTION

Exceptions can either be of two types:
1. Predefined Exceptions
2. User-defined Exceptions

PREDEFINED EXCEPTIONS

Predefined exceptions are internally defined by runtime system. Predefined exceptions are raised implicitly whenever PL/SQL program violates an ORACLE rule or exceeds a system-dependent limit. Every Oracle error has a number, but exceptions must be handled by name. So, PL/SQL predefines some common ORACLE errors as exceptions.
For example, if you try to divide a number by zero then PL/SQL raises an exception called ZERO_DIVIDE and if SELECT can not find a record then PL/SQL raises exception VO_DATA_FOUND.

Syntax

WHEN [exception-identifier] THEN [actions];
Where [actions] may be one or more PL/SQL or SQL statements,
 each terminated by semi-colon.

Example:

* Following example gives the usage of ZERO_DIVIDE exception: 
   
 DECLARE

N NUMBER;
 BEGIN
N:= 10/0;
EXCEPTION
WHEN ZERO DIVIDE THEN DBMS_
OUTPUT -PUT_LINE(Zero Divide Error');
END ;

PL/SQL procedure successfully completed.

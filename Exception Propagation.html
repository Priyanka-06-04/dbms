Exception Propagation

When an exception is raised in the executable section of PL/SQL block, then it handled in the following manner:
* If the exception is handled in the current block, then the control passes to enclosing block.

 
        Syntax:
            

            BEGIN 
            STATEMENTS;
            BEGIN
            IF CONDITION THEN
            RAISE A;
             END IF;
            EXCEPTION
            WHEN A THEN
            STATEMENTS;
            END;
            STATEMENTS;
            EXCEPTION
            WHEN B THEN
            STATEMENTS;
            END;
            

        As exception A is handled in the inner block, 

        control resumes with enclosing block.

*If the exception is not handled in the current block, then the exception is propagati That means, the exception is sent to enclosing blocks one after another from inside outside until an error handler is found in one of the enclosing blocks or there are m more blocks to search for handlers.

*When an exception is not handled in any of the enclosing blocks then it is sent to host environment.

Example

* The following example explains the usage of User-defined Exception: 
Example:

            MyException EXCEPTION
            BEGIN
            IF TO CHAR(SYSDATE, 'DY')= 'SUN' THEN

Before Trigger

When defining a trigger, you can specify the trigger timing. That is, you can specify whether the trigger action is to be executed befure or after the triggering statement. BEFORE and AFTER apply to both statement and row triggers.

BEFORE triggers are commonly used to check the validity of the data before the action is performed. For instance, you can use BEFORE trigger to prevent deletion of row if deletion should not be allowed in the given case.

Types of BEFORE trigger:

* BEFORE INSERT trigger:BEFORE INSERT trigger: A BEFORE INSERT trigger means that Oracle will fire this trigger before the INSERT operation is executed.

Syntax for a BEFORE INSERT trigger is: 
            CREATE or REPLACE TRIGGER trigger_name
            BEFORE INSERT
            ON table_name
            [ FOR EACH ROW ]
            DECLARE
            -- variable declarations
            BEGIN
            -- trigger code
            EXCEPTION
            WHEN ...
            -- exception handling
            END;
* Create a trigger for the EMP table, which makes the entry in ENAME column in uppercase. 
Example 1:
           
            SQLS CREATE OR REPLACE TRIGGER UPP_TRIG
            
            BEFORE INSERT ON EMP
            
            FOR EACH ROW
            
            BEGIN
            
            :new.ENAME := UPPER(:new.ENAME);
            
            END;
            /
            Trigger created.
            SQL>

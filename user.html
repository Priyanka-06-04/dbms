Creating A User


The DBA creates the user by executing the CREATE USER statement.the user doesnot have any privilege at this point.The DBA can then grant privileges to that user.These privileges determines what the user can do at the database level.


Syntax

 
        CREATE USER user_name
        INDENTIFIED BY password;

Example

            CREATE USER PRIYANKA

            INDENTIFIED BY PAUL;

Once a user is create, the DBA can grant specific system privileges as well as object privilegeto user. The DBA uses the GRANT command to allocate system and object privilege to the user.

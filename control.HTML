Conditional Control

The Structure of PL/SQL IF statement is similar to the Structure of IF statements in other procedural languages. It allows PL/SQL to perform actions selectively based on conditions.

There are three forms of IF statement:
  • IF-THEN-ENDIF
  • IF-THEN-ELSE-ENDIF
  • IF-THEN-ELSIF-ENDIF

(i) IF-THEN-ENDIF

Syntax: 
            IF condition   
            THEN   
            Statement: {It is executed when condition is true}  
            END IF;
This syntax is used when you want to execute statements only when condition is TRUE.

Example:

 
    DECLARE  
    a number(3) := 500;  
    BEGIN  
    -- check the boolean condition using if statement   
    IF( a < 20 ) THEN  
       -- if condition is true then print the following    
       dbms_output.put_line('a is less than 20 ' );  
    ELSE  
       dbms_output.put_line('a is not less than 20 ' );  
    END IF;  
    dbms_output.put_line('value of a is : ' || a);  
    END;

(ii)IF-THEN-ELSE-ENDIF

Syntax: 
    IF condition   
    THEN   
    Statement: 
    {It is executed when condition is true}  
    ELSE 
     statements;
    END IF; 
            
       
        
(iii)IF-THEN-ELSIF-ENDIF 

        Syntax:

    IF condition1   
    THEN  
    {...statements to execute when condition1 is TRUE...}  
    ELSIF condition2   
    THEN  
    {...statements to execute when condition2 is TRUE...}  
    ELSE  
     {...statements to execute when both condition1 and condition2 are FALSE...}  
    END IF;

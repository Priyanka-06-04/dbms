Case Expressions

A case Expressions selects a result and return it.To select the result, the case expression uses a selector,and expression whose value is used to select one of several alternatives.The selector is followed by one or more WHEN clauses, which are clicked sequentailly.The value of the selector determines which clause is executed.If the value of selector equals the values of a WHEN- clause expression WHEN clause is executed.

Syntax:

            CASE   
               when search_condition then  result;
               when search_condition then  result; 
               when search_condition then  result;
               when search_condition then  result; 
               when search_condition then  result;
               else result;  
           
         END;


Example:

 DECLARE  
    grade char(1) := 'A';  
 BEGIN  
 CASE grade 
when 'A' then dbms_output.put_line('Excellent');  
when 'B' then dbms_output.put_line('Very good');  
when 'C' then dbms_output.put_line('Good');  
when 'D' then dbms_output.put_line('Average');  
when 'F' then dbms_output.put_line('Passed with Grace');  
else dbms_output.put_line('Failed'); 
        
 END CASE;  
 END;
